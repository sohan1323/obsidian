
---
**Purpose:** Move or rename files/directories.

### Syntax

```
mv [OPTION]... SOURCE... DESTINATION
```

### Important options

|Option|Meaning|
|---|---|
|`-i`|Ask before overwriting|
|`-f`|Force|
|`-n`|Don't overwrite|
|`-v`|Verbose|
|`-u`|Move only when source is newer|

### Examples

Rename a file:

```
mv old.txt new.txt
```

Move a file:

```
mv file.txt /tmp/
```

Move and rename:

```
mv file.txt /tmp/newname.txt
```

Move directory:

```
mv project /home/user/
```

Interactive:

```
mv -i file.txt /tmp/
```

### Important concept

Linux doesn't have a separate `rename` command for normal file operations.

Renaming is simply:

```
mv old_name new_name
```


---
Displays help information for CMD commands.

### Syntax

```powershell
help [command]
```

### Arguments

|Argument|Meaning|
|---|---|
|`command`|Command whose help you want|

### Examples

```
help
```

Displays a list of available commands.

```
help dir
```

Displays detailed help for `dir`.

```
help copy
```

Displays help for `copy`.

You can also use:

```
dir /?
```

This is often more convenient than `help dir`.

### Important

Most CMD commands support:

```
command /?
```

Example:

```
ipconfig /?
```

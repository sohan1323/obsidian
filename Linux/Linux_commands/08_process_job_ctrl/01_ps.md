
---
**Purpose:** Display information about running processes.

### Syntax

```
ps [OPTIONS]
```

### Basic

```
ps
```

Shows processes associated with the current shell.

Example:

```
 PID TTY          TIME CMD
 421 pts/0    00:00:00 bash
 582 pts/0    00:00:00 ps
```

---

## Important options

### `ps aux`

```
ps aux
```

A very commonly used form.

Shows processes for all users with detailed information.

Typical columns:

```
USER
PID
%CPU
%MEM
VSZ
RSS
TTY
STAT
START
TIME
COMMAND
```

### `ps -ef`

```
ps -ef
```

Another common full-process listing.

---

### `ps -u USER`

```
ps -u alice
```

Show processes belonging to Alice.

### `ps -p PID`

```
ps -p 1234
```

Show information about a specific PID.

### Custom output

```
ps -eo pid,user,%cpu,%mem,comm
```

Useful columns:

```
PID
USER
CPU
MEM
COMMAND
```

### Find a process with `grep`

```
ps aux | grep ssh
```

This searches the output for `ssh`.

A better method for exact process matching is often:

```
pgrep -a ssh
```

which we'll cover below.

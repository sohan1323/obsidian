
---
Many Linux systems maintain traditional log files under:

```
/var/log/
```

List them:

```
ls -lah /var/log/
```

Common files include:

```
/var/log/syslog
/var/log/messages
/var/log/auth.log
/var/log/kern.log
/var/log/dmesg
```

Exact files depend on the distribution and logging configuration.

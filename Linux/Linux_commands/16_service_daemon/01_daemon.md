
---
A **daemon** is a background process that provides a service without normally requiring direct user interaction.

Examples:

```
sshd       → SSH service
cron       → scheduled tasks
systemd    → service/system management
NetworkManager → network management
nginx      → web server
```

Daemon names commonly end with:

```
d
```

Examples:

```
sshd
systemd
udevd
journald
```

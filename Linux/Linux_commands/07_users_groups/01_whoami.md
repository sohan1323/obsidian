
---
**Purpose:** Display the username of the current effective user.

### Syntax

```
whoami
```

### Example

```
whoami
```

Output:

```
sohan
```

If you're root:

```
root
```

### Practical use

Check which user you're currently operating as:

```
whoami
```

This is especially useful after:

```
sudo -s
```

or:

```
su
```


---
**Purpose:** Display file contents in different numerical representations, such as octal, hexadecimal, decimal, or ASCII.

`od` stands for **octal dump**.

### Syntax

```
od [OPTION]... [FILE]
```

### Important options

|Option|Meaning|
|---|---|
|`-c`|Character representation|
|`-x`|Hexadecimal|
|`-d`|Decimal|
|`-o`|Octal|
|`-b`|Octal bytes|
|`-A`|Select address/radix format|

### Examples

Hexadecimal:

```
od -x file.bin
```

Character representation:

```
od -c file.txt
```

Decimal:

```
od -d file.bin
```

### Practical use

Useful when examining binary data or unusual characters that aren't obvious in normal text output.

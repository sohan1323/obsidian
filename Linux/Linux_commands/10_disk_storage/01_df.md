
---
Shows **filesystem disk-space usage**.

### Syntax

```
df [OPTION] [FILE]
```

### Important options

|Option|Purpose|
|---|---|
|`-h`|Human-readable|
|`-H`|Human-readable using powers of 1000|
|`-T`|Show filesystem type|
|`-i`|Show inode usage|
|`-a`|Show all filesystems|
|`-x TYPE`|Exclude filesystem type|

### Examples

```
df
```

```
df -h
```

Example:

```
Filesystem      Size  Used Avail Use% Mounted on
/dev/sda2        50G   32G   16G  67% /
```

Show filesystem type:

```
df -hT
```

Check a specific directory:

```
df -h /var
```

Check inode usage:

```
df -ih
```

### Practical use

Find which mounted filesystem is running out of space:

```
df -h
```

Check inode exhaustion:

```
df -ih
```

A filesystem can have free disk space but still fail because it has **no free inodes**.


---
`at` schedules a command to run **once** at a specified time.

Example:

```
at 15:30
```

Then enter:

```
echo "Task executed"
```

Finish with:

```
Ctrl+D
```

The job runs once at 15:30.

---

#  `at` Time Expressions

Examples:

```
at 10:30
```

```
at 10:30 tomorrow
```

```
at now + 1 hour
```

```
at now + 30 minutes
```

```
at midnight
```

---

#  `atq`

List scheduled `at` jobs:

```
atq
```

Example:

```
3   Wed Sep 23 15:30:00 2026 a user
```

The first number is the job ID.

---

#  `atrm`

Remove an `at` job.

```
atrm 3
```

Where `3` is the job ID returned by:

```
atq
```


---
Renames files or directories.

### Syntax

```
ren oldname newname
```

### Example

```
ren old.txt new.txt
```

### Rename extension

```
ren *.txt *.log
```

Be careful with wildcard renaming.

### Directory

```
ren oldfolder newfolder
```

`ren` does **not** move an item to another directory.

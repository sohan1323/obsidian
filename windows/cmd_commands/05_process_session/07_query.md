
---
`query` is a family of commands for querying Windows sessions and related information.

### Syntax

```
query [command]
```

Common forms include:

```
query user
query session
query process
query termserver
```

---

## `query user`

```
query user
```

Shows logged-in users and sessions.

---

## `query session`

```
query session
```

Shows session information.

---

## `query process`

```
query process
```

Displays processes associated with sessions.

---

## Why this matters

In Windows administration and authorized security assessment, session enumeration helps identify:

- logged-in users
- active sessions
- session IDs
- console/RDP sessions

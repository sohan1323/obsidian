
---
**Purpose:** Interactive and more user-friendly process viewer.

### Syntax

```
htop
```

On systems where it isn't installed:

```
sudo apt install htop
```

### Example

```
htop
```

It provides:

- CPU usage
- Memory usage
- Swap usage
- Processes
- Users
- Process tree
- Interactive process management

### Useful keys

|Key|Action|
|---|---|
|`F1`|Help|
|`F2`|Setup|
|`F3`|Search|
|`F4`|Filter|
|`F5`|Tree view|
|`F6`|Sort|
|`F9`|Kill|
|`F10`|Quit|

### Practical use

For interactive process investigation, `htop` is generally easier to use than `top`.

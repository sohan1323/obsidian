
---
Handles many archive formats using **7-Zip**.

Common formats include:

- `.7z`
- `.zip`
- `.tar`
- `.gz`
- `.bz2`
- `.xz`

Depending on the installed 7-Zip implementation/package, the executable may be `7z` or `7zz`.

### Syntax

```
7z COMMAND [OPTIONS] ARCHIVE [FILES...]
```

### Important commands

|Command|Purpose|
|---|---|
|`a`|Add/create archive|
|`x`|Extract with full paths|
|`e`|Extract without full paths|
|`l`|List archive|
|`t`|Test archive|
|`d`|Delete from archive|

### Examples

Create archive:

```
7z a backup.7z project/
```

List:

```
7z l backup.7z
```

Extract:

```
7z x backup.7z
```

Extract to directory:

```
7z x backup.7z -o/tmp/project
```

Test:

```
7z t backup.7z
```

Create ZIP:

```
7z a backup.zip project/
```

### Practical security use

Inspect an archive:

```
7z l suspicious.7z
```

Test integrity:

```
7z t suspicious.7z
```


---
Displays or manages computer accounts in a domain.

### Syntax

```
net computer
net computer \\ComputerName /add
net computer \\ComputerName /delete
```

### List computer accounts

```
net computer
```

### Add computer account

```
net computer \\LAB-PC01 /add
```

### Delete computer account

```
net computer \\LAB-PC01 /delete
```

Domain permissions are required.

This command is more relevant to domain administration than standalone Windows systems.

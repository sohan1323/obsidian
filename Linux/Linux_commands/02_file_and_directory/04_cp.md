
---
**Purpose:** Copy files and directories.

### Syntax

```
cp [OPTION]... SOURCE... DESTINATION
```

### Important options

|Option|Meaning|
|---|---|
|`-r` / `-R`|Copy directories recursively|
|`-i`|Ask before overwriting|
|`-f`|Force overwrite|
|`-v`|Verbose|
|`-n`|Don't overwrite existing files|
|`-p`|Preserve permissions, timestamps, ownership where possible|
|`-a`|Archive; preserve as much metadata as possible|
|`-u`|Copy only when source is newer|

### Examples

Copy a file:

```
cp file.txt backup.txt
```

Copy to another directory:

```
cp file.txt /tmp/
```

Copy multiple files:

```
cp file1.txt file2.txt /tmp/
```

Copy directory:

```
cp -r project /tmp/
```

Interactive overwrite:

```
cp -i file.txt /tmp/
```

Verbose:

```
cp -v file.txt /tmp/
```

Preserve metadata:

```
cp -p file.txt backup.txt
```

Archive a directory:

```
cp -a project project_backup
```

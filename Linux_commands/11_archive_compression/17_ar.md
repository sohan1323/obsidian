
---
Creates and extracts **Unix archive libraries**.

It is especially important when working with Debian packages and static libraries.

### Syntax

```
ar [OPTION] ARCHIVE FILES...
```

### Examples

List archive:

```
ar t archive.a
```

Extract:

```
ar x archive.a
```

Create archive:

```
ar rcs libexample.a file1.o file2.o
```

### Practical use

Inspect static libraries:

```
ar t libexample.a
```

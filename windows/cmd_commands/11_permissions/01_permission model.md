```
File / Directory
       │
       ├── Owner
       │
       ├── DACL
       │    ├── Allow
       │    └── Deny
       │
       └── SACL
            └── Auditing
```

### DACL

**Discretionary Access Control List**

Controls who can access an object and what they can do.

Examples:

```
Read
Write
Modify
Delete
Full Control
```

### SACL

**System Access Control List**

Controls which access attempts are audited

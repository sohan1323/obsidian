
---
Displays installed device drivers.

### Syntax

```
driverquery [options]
```

### Basic

```
driverquery
```

### `/v`

Verbose information:

```
driverquery /v
```

### `/fo`

Output format:

```
driverquery /fo table
```

```
driverquery /fo list
```

```
driverquery /fo csv
```

### `/si`

Displays signed-driver information:

```
driverquery /si
```

### Save output

```
driverquery /v > drivers.txt
```

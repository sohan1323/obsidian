
---
`ip` is the primary modern Linux networking utility.

It replaces many older commands such as `ifconfig`, `route`, and `arp`.

### Syntax

```
ip [OBJECT] [COMMAND] [OPTIONS]
```

Common objects:

```
address
link
route
neigh
rule
```

---

## `ip addr`

### Purpose

Displays and manages IP addresses assigned to interfaces.

```
ip addr
```

Short form:

```
ip a
```

Show a specific interface:

```
ip addr show eth0
```

Show only IPv4:

```
ip -4 addr
```

Show only IPv6:

```
ip -6 addr
```

### Example output

```
2: eth0:
    inet 192.168.1.20/24
    inet6 fe80::....
```

Important information:

- interface name
- IPv4 address
- IPv6 address
- subnet prefix
- MAC address
- interface state

### Practical use

Basic network enumeration:

```
ip addr
```

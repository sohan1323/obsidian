
---
**Purpose:** Switch to another user.

`su` means **substitute user**.

### Syntax

```
su [OPTIONS] [USER]
```

Switch to root:

```
su
```

Switch to another user:

```
su alice
```

---

## Login shell

```
su - alice
```

or:

```
su -l alice
```

This starts a login shell and loads the target user's login environment.

### Important options

|Option|Meaning|
|---|---|
|`-` / `-l`|Login shell|
|`-c COMMAND`|Execute command|
|`-s SHELL`|Specify shell|

Example:

```
su -c "whoami" alice
```

Output:

```
alice
```

### `su` vs `su -`

```
su alice
```

switches the user while retaining much of the current environment.

```
su - alice
```

starts a login environment for Alice.


---
**Purpose:** Number lines in a file.

### Syntax

```
nl [OPTION]... [FILE]...
```

### Important options

|Option|Meaning|
|---|---|
|`-b a`|Number all lines|
|`-b t`|Number only non-empty lines|
|`-n ln`|Left-justified numbering|
|`-n rn`|Right-justified numbering|
|`-w NUMBER`|Set width of line numbers|

### Examples

```
nl file.txt
```

Number all lines:

```
nl -b a file.txt
```

Set number width:

```
nl -w 4 file.txt
```

### `cat -n` vs `nl`

Both can number lines:

```
cat -n file.txt
```

and:

```
nl file.txt
```

`nl` provides more control over numbering.

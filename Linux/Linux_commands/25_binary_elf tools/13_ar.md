
---
Creates and extracts static libraries.

Static libraries usually use:

```
.a
```

Example:

```
libexample.a
```

---

## List archive contents

```
ar -t libexample.a
```

---

## Extract

```
ar -x libexample.a
```

---

## Create archive

```
ar rcs libexample.a file1.o file2.o
```

Options:

| Option | Meaning              |
| ------ | -------------------- |
| `r`    | Insert/replace files |
| `c`    | Create archive       |
| `s`    | Create symbol index  |
| `t`    | List contents        |
| `x`    | Extract              |

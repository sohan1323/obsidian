
---
Displays kernel/system information.

### Basic

```
uname
```

Example:

```
Linux
```

### Important options

|Option|Meaning|
|---|---|
|`-a`|All available information|
|`-s`|Kernel name|
|`-r`|Kernel release/version|
|`-v`|Kernel version/build information|
|`-m`|Machine architecture|
|`-p`|Processor type|
|`-o`|Operating system|

Examples:

```
uname -r
```

Shows kernel release.

```
uname -m
```

Shows architecture:

```
x86_64
```

Complete:

```
uname -a
```

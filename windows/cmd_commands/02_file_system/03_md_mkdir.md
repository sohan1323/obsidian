
---
Both commands create directories.

```
md folder
```

or:

```
mkdir folder
```

### Syntax

```
mkdir [drive:]path
```

### Create directory

```
mkdir projects
```

### Create nested directories

```
mkdir C:\Lab\Windows\Commands
```

CMD can create intermediate directories when required.

### Multiple directories

```
mkdir test1 test2 test3
```

Creates multiple directories.


---
Node.js package manager.

### Check version

```
npm --version
```

### Install package

```
npm install express
```

### Install globally

```
npm install -g nodemon
```

### Remove

```
npm uninstall express
```

### List packages

```
npm list
```

Global:

```
npm list -g
```

### Install project dependencies

If a project contains `package.json`:

```
npm install
```

### Run package scripts

```
npm run dev
```

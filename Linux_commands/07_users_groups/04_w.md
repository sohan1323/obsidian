
---
**Purpose:** Show logged-in users **and what they're currently doing**.

### Syntax

```
w [OPTIONS] [USER]
```

### Example

```
w
```

Possible output:

```
USER    TTY   FROM          LOGIN@   IDLE   WHAT
sohan   pts/0 192.168.1.20 14:30    2m     bash
```

Compared with `who`, `w` provides more information about the users' current activity.

### Important options

|Option|Meaning|
|---|---|
|`-h`|Don't show header|
|`-s`|Short format|
|`-f`|Show/hide FROM field|
|`-u`|Display user CPU usage|

### Practical security use

Check who is currently logged in:

```
w
```

and investigate unexpected sessions.


---
`cd` means **Change Directory**.

### Syntax

```
cd [/d] [path]
```

### Current directory

```
cd
```

Displays the current directory.

### Change directory

```
cd C:\Windows
```

### Parent directory

```
cd ..
```

Example:

```
C:\Users\Sohan\Documents
```

After:

```
cd ..
```

you get:

```
C:\Users\Sohan
```

### Multiple levels

```
cd ..\..
```

Moves up two levels.

### Root

```
cd \
```

Moves to the root of the current drive.

Example:

```
C:\Users\Sohan
```

becomes:

```
C:\
```

### `/D`

Important difference:

```
cd D:\Tools
```

doesn't necessarily switch the active drive when used from another drive.

Use:

```
cd /d D:\Tools
```

This changes both:

- drive
- directory

Example:

```
C:\Users\Sohan>cd /d D:\Projects

D:\Projects>
```


---
CMD expands environment variables using:

```
%VARIABLE%
```

Example:

```
echo %USERNAME%
```

```
echo %COMPUTERNAME%
```

```
echo %USERPROFILE%
```

```
echo %TEMP%
```

```
echo %PATH%
```

### Common variables

|Variable|Meaning|
|---|---|
|`%USERNAME%`|Current username|
|`%USERPROFILE%`|User profile directory|
|`%COMPUTERNAME%`|Computer name|
|`%SYSTEMROOT%`|Windows directory|
|`%WINDIR%`|Windows directory|
|`%TEMP%`|Temporary directory|
|`%TMP%`|Temporary directory|
|`%PATH%`|Executable search path|
|`%CD%`|Current directory|
|`%DATE%`|Current date|
|`%TIME%`|Current time|
|`%ERRORLEVEL%`|Previous command's exit code|

Example:

```
echo User: %USERNAME%
echo Computer: %COMPUTERNAME%
echo Directory: %CD%
```

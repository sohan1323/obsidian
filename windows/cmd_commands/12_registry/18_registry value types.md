
---
### `REG_SZ`

Normal string.

```
"C:\Program Files\App"
```

### `REG_EXPAND_SZ`

String containing environment variables.

```
"%SystemRoot%\System32"
```

### `REG_MULTI_SZ`

Multiple strings.

```
Server1
Server2
Server3
```

### `REG_DWORD`

32-bit integer.

```
0
1
100
```

### `REG_QWORD`

64-bit integer.

### `REG_BINARY`

Raw binary data.

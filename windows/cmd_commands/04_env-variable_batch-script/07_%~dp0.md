
---
This is one of the most important batch-script constructs.

Suppose:

```
C:\Scripts\backup.bat
```

contains:

```
echo %~dp0
```

Running it prints:

```
C:\Scripts\
```

`%0` represents the batch file itself.

The modifiers:

```
%~d0 → drive
%~p0 → path
%~dp0 → drive + path
```

Example:

```
echo Script location: %~dp0
```

This allows a script to refer to files relative to its own location.

For example:

```
copy "%~dp0config.txt" C:\Backup\
```

This works even if you execute the script from another directory.

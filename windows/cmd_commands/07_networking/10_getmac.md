
---
Displays MAC addresses associated with network adapters.

### Syntax

```
getmac [/s computer] [/u user] [/p password] [/fo format] [/nh] [/v]
```

### Basic

```
getmac
```

### Verbose

```
getmac /v
```

### CSV

```
getmac /fo csv
```

### Remote computer

```
getmac /s COMPUTER01
```

Remote queries require appropriate permissions and configuration.


---
**Purpose:** Create links to files.

There are two major types:

1. **Hard links**
2. **Symbolic/soft links**

### Syntax

```
ln [OPTION] TARGET LINK_NAME
```

---

### Hard link

```
ln original.txt hardlink.txt
```

Both directory entries refer to the same underlying inode/data.

Check:

```
ls -li original.txt hardlink.txt
```

They normally show the same inode number.

### Symbolic link

Use `-s`:

```
ln -s original.txt symlink.txt
```

Now:

```
original.txt
     ↑
     |
symlink.txt
```

Check:

```
ls -l symlink.txt
```

You may see:

```
symlink.txt -> original.txt
```

### Important options

| Option | Meaning                     |
| ------ | --------------------------- |
| `-s`   | Create symbolic link        |
| `-f`   | Force                       |
| `-i`   | Ask before replacing        |
| `-v`   | Verbose                     |
| `-L`   | Follow symbolic links       |
| `-P`   | Don't follow symbolic links |

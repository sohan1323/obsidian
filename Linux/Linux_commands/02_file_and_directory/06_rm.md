
---
**Purpose:** Remove files and directories.

⚠️ `rm` normally permanently removes files rather than moving them to a graphical trash/recycle bin.

### Syntax

```
rm [OPTION]... FILE...
```

### Important options

|Option|Meaning|
|---|---|
|`-i`|Ask before deletion|
|`-f`|Force deletion|
|`-r` / `-R`|Recursively remove directories|
|`-v`|Verbose|
|`-d`|Remove empty directories|

### Examples

Delete a file:

```
rm file.txt
```

Delete multiple files:

```
rm file1.txt file2.txt
```

Interactive deletion:

```
rm -i file.txt
```

Delete directory and contents:

```
rm -r project
```

Force recursive deletion:

```
rm -rf project
```

### Very important

Be extremely careful with:

```
rm -rf
```

For example:

```
rm -rf /some/path
```

can recursively delete everything under that path.

Before using `rm` on a complicated path, verify it:

```
pwd
ls
```

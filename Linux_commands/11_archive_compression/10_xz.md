
---
Compresses files using the **XZ/LZMA2** compression algorithm.

### Syntax

```
xz [OPTION] FILE
```

### Important options

|Option|Purpose|
|---|---|
|`-d`|Decompress|
|`-k`|Keep original|
|`-c`|Write to stdout|
|`-1` to `-9`|Compression level|
|`-T`|Number of threads|

### Examples

```
xz file.txt
```

Produces:

```
file.txt.xz
```

Decompress:

```
xz -d file.txt.xz
```

Keep original:

```
xz -k file.txt
```

Use multiple CPU threads:

```
xz -T4 file.txt
```

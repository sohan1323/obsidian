
---
Displays symbols from object files and executables.

### Syntax

```
nm [OPTIONS] FILE
```

Example:

```
nm ./program
```

Typical output:

```
0000000000401126 T main
0000000000404010 D variable
                 U printf
```

Important symbol types:

|Symbol|Meaning|
|---|---|
|`T`|Text/code|
|`t`|Local text/code|
|`D`|Initialized data|
|`B`|BSS|
|`R`|Read-only data|
|`U`|Undefined/external symbol|
|`W`|Weak symbol|

---

## Demangle C++ symbols

```
nm -C ./program
```

---

## Dynamic symbols

```
nm -D ./program
```

---

## Sort by address

```
nm -n ./program
```

### Security use

Find functions such as:

```
main
system
printf
malloc
free
```

and determine whether symbols are present or stripped.

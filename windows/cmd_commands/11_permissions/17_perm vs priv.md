### Permission

Usually controls access to an object.

Example:

```
Alice → C:\Lab\file.txt → Read
```

### Privilege

Controls whether a security principal can perform certain system-level operations.

Example:

```
SeShutdownPrivilege
```

Think:

```
Permission
    ↓
"Can I access this object?"

Privilege
    ↓
"Can I perform this privileged system operation?"
```

## `sc query`

Displays service information.

### Syntax

```
sc query [ServiceName]
```

### Examples

List services:

```
sc query
```

Query a specific service:

```
sc query Spooler
```

Query a remote computer:

```
sc \\SERVER01 query Spooler
```

### Useful output

```
SERVICE_NAME: Spooler
        TYPE               : 110  WIN32_OWN_PROCESS
        STATE              : 4  RUNNING
        WIN32_EXIT_CODE    : 0
        SERVICE_EXIT_CODE  : 0
        CHECKPOINT         : 0
        WAIT_HINT          : 0
```

Important fields:

|Field|Meaning|
|---|---|
|`SERVICE_NAME`|Internal service name|
|`TYPE`|Type of service|
|`STATE`|Current state|
|`WIN32_EXIT_CODE`|Service/process exit status|
|`CHECKPOINT`|Startup/shutdown progress|
|`WAIT_HINT`|Expected wait time|

Common states:

```
STOPPED
START_PENDING
STOP_PENDING
RUNNING
PAUSE_PENDING
PAUSED
CONTINUE_PENDING
```

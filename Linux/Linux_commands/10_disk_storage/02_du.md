
---
Shows how much disk space files and directories consume.

### Syntax

```
du [OPTION] [FILE/DIRECTORY]
```

### Important options

|Option|Purpose|
|---|---|
|`-h`|Human-readable|
|`-s`|Summary|
|`-a`|Include files|
|`-d N`|Maximum directory depth|
|`-x`|Stay on one filesystem|
|`-c`|Show total|
|`--max-depth=N`|Directory depth|

### Examples

Current directory:

```
du -h .
```

Directory summary:

```
du -sh .
```

Find large directories:

```
du -h --max-depth=1 /
```

Common example:

```
du -sh /var/*
```

Sort directories by size:

```
du -h --max-depth=1 /var | sort -h
```

### Practical use

Find what is consuming disk space:

```
du -h --max-depth=1 / | sort -h
```

For a particular directory:

```
du -h --max-depth=1 /var | sort -h
```


---
Linux commands normally work with **three standard streams**:

```
stdin  (0) → Standard input
stdout (1) → Standard output
stderr (2) → Standard error
```

They can be redirected between files and commands.

---

## 1. Standard Input — `stdin`

File descriptor:

```
0
```

Normally comes from the keyboard.

Example:

```
cat
```

Type:

```
hello
```

Press `Ctrl+D` to send EOF.



## 2. Standard Output — `stdout`

File descriptor:

```
1
```

Normally goes to the terminal.

```
echo "Hello"
```

Output is sent to stdout.


## 3. Standard Error — `stderr`

File descriptor:

```
2
```

Used for errors and diagnostic messages.

Example:

```
ls /does-not-exist
```

The error is sent to stderr.

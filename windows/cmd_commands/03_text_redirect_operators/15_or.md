
---
Executes the second command if the first command fails.

```
command1 || command2
```

Example:

```
dir C:\DoesNotExist || echo Directory not found
```

You can combine them:

```
command1 && command2 || command3
```

Conceptually:

```
command1
   │
   ├── success → command2
   │
   └── failure → command3
```

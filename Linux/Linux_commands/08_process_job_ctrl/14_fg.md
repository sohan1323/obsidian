
---
**Purpose:** Bring a background/stopped job to the foreground.

### Syntax

```
fg [JOB]
```

Example:

```
fg %1
```

This brings job 1 back to the foreground.

---

# Background execution

You can start a command directly in the background:

```
./script.sh &
```

The `&` tells the shell to run the command asynchronously.

Check:

```
jobs
```

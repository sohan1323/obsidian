
---
**Purpose:** Lists files and directories.

### Syntax

```bash
ls [OPTION]... [FILE]...
```

### Important options

|Option|Meaning|
|---|---|
|`-l`|Long/detailed listing|
|`-a`|Show hidden files|
|`-A`|Show hidden files except `.` and `..`|
|`-h`|Human-readable sizes|
|`-R`|Recursive listing|
|`-t`|Sort by modification time|
|`-S`|Sort by file size|
|`-r`|Reverse sorting|
|`-d`|Show directory itself, not its contents|
|`-i`|Show inode number|
|`-F`|Append indicators such as `/`, `*`|
|`-1`|One entry per line|

### Examples

Basic:

```
ls
```

Detailed:

```
ls -l
```

Show hidden files:

```
ls -a
```

Detailed + hidden:

```
ls -la
```

Human-readable sizes:

```
ls -lh
```

Combine options:

```
ls -lah
```

List `/var/log`:

```
ls /var/log
```

List recursively:

```
ls -R /etc
```

Sort by modification time:

```
ls -lt
```

Sort by file size:

```
ls -lS
```

Show inode numbers:

```
ls -li
```

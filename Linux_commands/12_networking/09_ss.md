
---
Displays network sockets and connections.

It is the modern replacement for much of `netstat`.

### Syntax

```
ss [OPTIONS]
```

### Important options

|Option|Purpose|
|---|---|
|`-t`|TCP|
|`-u`|UDP|
|`-l`|Listening sockets|
|`-n`|Numeric addresses/ports|
|`-p`|Show processes|
|`-a`|All sockets|
|`-4`|IPv4|
|`-6`|IPv6|
|`-s`|Socket statistics|

### Examples

Show listening TCP ports:

```
ss -ltn
```

Show listening TCP/UDP ports:

```
ss -lntup
```

Show processes:

```
sudo ss -lntup
```

Show established TCP connections:

```
ss -tn state established
```

Show all TCP connections:

```
ss -ant
```

Show socket summary:

```
ss -s
```

### Practical security use

Enumerate locally listening services:

```
sudo ss -lntup
```

Example:

```
LISTEN 0 128 0.0.0.0:22
LISTEN 0 128 127.0.0.1:8080
```

This tells you which ports are listening and, with `-p`, which processes own them.

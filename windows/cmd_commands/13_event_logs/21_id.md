
---
Specifies event ID.

```
eventcreate /ID 100 /L APPLICATION /T INFORMATION /SO LabTest /D "Test event"
```

# `/L`

Specifies the event log.

Common values:

```
APPLICATION
SYSTEM
```

Example:

```
eventcreate /ID 200 /L SYSTEM /T WARNING /SO LabTest /D "Warning test"
```

# `/T`

Specifies event type.

Common values:

```
ERROR
WARNING
INFORMATION
```

Example:

```
eventcreate /ID 101 /L APPLICATION /T ERROR /SO LabTest /D "Test error"
```

# `/SO`

Specifies event source.

```
eventcreate /ID 102 /L APPLICATION /T INFORMATION /SO MyApplication /D "Application started"
```

# `/D`

Specifies event description.

```
eventcreate /ID 103 /L APPLICATION /T INFORMATION /SO LabTest /D "Windows CLI event test"
```

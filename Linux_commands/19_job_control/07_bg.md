
---
Continues a stopped job in the background.

Suppose:

```
[1]+  Stopped    ping 127.0.0.1
```

Run:

```
bg %1
```

Now:

```
[1]+  Running    ping 127.0.0.1 &
```

The process continues running while you have the shell prompt.

Without specifying a job:

```
bg
```

usually operates on the current/default job.

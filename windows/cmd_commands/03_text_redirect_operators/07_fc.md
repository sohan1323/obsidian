
---
`fc` means **File Compare**.

It compares files.

### Syntax

```
fc [options] file1 file2
```

### Basic

```
fc file1.txt file2.txt
```

It reports differences.

### `/N`

Show line numbers:

```
fc /n file1.txt file2.txt
```

### `/B`

Binary comparison:

```
fc /b file1.bin file2.bin
```

Useful for comparing binary files byte-by-byte.

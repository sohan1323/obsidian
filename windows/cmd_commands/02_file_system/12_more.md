Displays output one screen at a time.

### Syntax

```
more [options] [filename]
```

### Example

```
more large.txt
```

Or:

```
type large.txt | more
```

### `/E`

Enable extended functionality.

```
more /e large.txt
```

### Common interactive keys

While `more` is running:

```
Space → next page
Enter → next line
Q     → quit
```


---
**Purpose:** Display the current user's UID, GID, and group memberships.

### Syntax

```
id [OPTIONS] [USER]
```

### Example

```
id
```

Possible output:

```
uid=1000(sohan) gid=1000(sohan) groups=1000(sohan),27(sudo),100(users)
```

This tells you:

```
UID  → User ID
GID  → Primary Group ID
groups → Supplementary groups
```

### Check another user

```
id root
```

### Important options

|Option|Meaning|
|---|---|
|`-u`|Show UID|
|`-g`|Show primary GID|
|`-G`|Show all group IDs|
|`-n`|Show names instead of numbers|
|`-un`|Show username|
|`-gn`|Show primary group name|
|`-Gn`|Show group names|

Examples:

```
id -u
```

Output:

```
1000
```

```
id -un
```

Output:

```
sohan
```

```
id -Gn
```

Shows all groups:

```
sohan sudo users
```

### Practical cybersecurity use

When enumerating a Linux system:

```
id
```

quickly tells you:

- Current UID
- Primary group
- Supplementary groups
- Whether you're in potentially privileged groups such as `sudo`

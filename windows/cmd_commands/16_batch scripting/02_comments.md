## `rem`

```
rem This is a comment
```

Example:

```
@echo off

rem Display system information
systeminfo

rem Display current user
whoami
```

## `::`

```
:: This is commonly used as a comment
```

Example:

```
@echo off

:: Network information
ipconfig /all
```

`REM` is the official comment syntax. `::` is a commonly used batch idiom, but it is technically a label syntax and has edge cases.

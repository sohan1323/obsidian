
---
Manages Flatpak applications.

### List installed applications

```
flatpak list
```

### Search

```
flatpak search firefox
```

### Install

```
flatpak install flathub org.example.App
```

### Run

```
flatpak run org.example.App
```

### Update

```
flatpak update
```

### Remove

```
flatpak uninstall org.example.App
```

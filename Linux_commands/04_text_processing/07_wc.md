
---
**Purpose:** Count lines, words, and bytes.

### Syntax

```
wc [OPTIONS] [FILE]
```

### Important options

|Option|Meaning|
|---|---|
|`-l`|Lines|
|`-w`|Words|
|`-c`|Bytes|
|`-m`|Characters|
|`-L`|Longest line length|

### Examples

Count lines:

```
wc -l file.txt
```

Count words:

```
wc -w file.txt
```

Count bytes:

```
wc -c file.txt
```

Count characters:

```
wc -m file.txt
```

### Practical use

Count users:

```
wc -l /etc/passwd
```

Count matching results:

```
grep "failed" auth.log | wc -l
```

This tells you how many matching lines were found.

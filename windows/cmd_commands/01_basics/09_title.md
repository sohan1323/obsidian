
---
Changes the CMD window title.

### Syntax

```
title [text]
```

### Arguments

|Argument|Meaning|
|---|---|
|`text`|New console window title|

### Examples

```
title Windows CLI Training
```

The CMD window title becomes:

```
Windows CLI Training
```

Useful when working with multiple terminal windows:

```
title Kali Lab - Windows Victim
```

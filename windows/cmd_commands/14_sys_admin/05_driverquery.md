
---
Lists installed drivers.

```
driverquery
```

### Verbose

```
driverquery /v
```

### Services format

```
driverquery /si
```

### CSV output

```
driverquery /fo csv
```

### Table output

```
driverquery /fo table
```

### List format

```
driverquery /fo list
```

### Remote computer

```
driverquery /s SERVER01
```

Useful for troubleshooting hardware and kernel-driver issues.
